## Fixes applied

### 1. `enclose` — strings are arrays (`evaluator.rs:8026`)

```rust
// Before:
APLValue::Number(_) | APLValue::Char(_) | APLValue::Str(_) => Ok(v.clone()),
// After:
APLValue::Number(_) | APLValue::Char(_) => Ok(v.clone()),
```

Kotlin `APLString` extends `APLArray` (types.kt:1627), not `APLSingleValue`. Strings must be enclosed like arrays.

Closes: `testWithScalarEnclosed` (`≠ ⊂"abc"` → `(1)`), `⊂"abc"` → `(abc)`, etc.

### 2. `ceil_floor_dyadic` — null+null errors (`evaluator.rs:12635-12644`)

### 3. `adverb_each` — scalar result (`evaluator.rs:11889-11898`)

```rust

    v.as_ref(),
    APLValue::Number(_) | APLValue::Char(_)

if is_true_scalar(&right_val)
    && left_val.as_ref().map_or(true, is_true_scalar)
{
    return match left_val {
        Some(lv) => self.apply_fn_instr(fn_instr, Some(&lv), &right_val, env),
```

### 4. `parse_assign` — single target required (`parser.rs:595-598`)

### 5. `enclose_axis` — requires array arg (`evaluator.rs:8045-8056`)

## Nil-split: `⍬` (empty array) vs `null` (nil singleton) — 2026-09-05 p.m.

**Root cause:** Kotlin has TWO values the port conflated into one `APLValue::Null`:
- `APLNullValue` (`⍬`, types.kt:1660) — an `APLArray` with `dimensions=[0]`
- `APLNilValue` (`null` keyword → `NilToken`, tokeniser.kt:843) — an `APLSingleValue`

Oracle proof: `⍬≡null` → `0`, `⍴⍬` → `(0)` but `⍴null` → `⍬`, `⍬+5` → `⍬` but `null+5` → `5`.

### Changes (`lib.rs`, `parser.rs`, `evaluator.rs`, 4 test files)

- New `APLValue::Nil` variant (`Null` keeps = empty marker, displays `⍬`; `Nil` displays `null`). `null` keyword now binds to `Nil`.
- `⍬` parses to a real empty `Instr::Array` (was `Instr::Empty` → `Null`).
- New `nil_dyadic` helper: `+` (nil+nil→0) / `×` (nil×nil→1) one-sided passthrough; `-`/`÷` left-nil errors, right-nil passes numbers/arrays, errors beside Char/Str. Wired into all four dyadic arms + `num2_impl` top rule (nested-cell recursion) + scalar-extension loops (nil strand elements) + `cmp2`/`cmp_cells` (`=`/`≠` value-like, ordering errors) + `⌊`/`⌈` one-sided identity + `total_equal`/`deep_equal`/`type_equal` `(Nil,Nil)` arms.
- Monadic `+null`/`-null` error; `⊂null` → `null` passthrough.
- `reshape` disclose-first body extracted to `reshape_disclose_first`, wired for real empty-array shapes (`⍬⍴1 2 3` → `1` still ✓).
- `cmp2_elements` empty-side guard (returns empty, no `v[0]` panic).
- `format_display`: empty rank≤1 arrays render `⍬` (oracle: `⍳0`, `⍴⊂5`, `↓⍬` all print `⍬`).
- Tests: 2 stale curated expectations fixed (`⍳0`, `⍴⊂5` `"()"`→`"⍬"`), `⊂⍬` enclose expectation `"(null)"`→`"(())"`, `show` helpers in null_propagation/member_deref handle `Nil`/empty, 6 new nil regression tests (all oracle-verified battery cases).
- Display note: `"ab"-null` errors with `Left arg: array` (port `class_name` for `Str` is `array`; Kotlin reports `char`). Message-insensitive for `kind:fails` conformance.
