### Semantics (READ from Kotlin, not guessed)
`collapseInt(withDiscard=false)`:
- rank-0 array → `EnclosedAPLValue.make(valueAt(0).collapse())` — disclose the single boxed
  element, collapse THAT, then RE-ENCLOSE it. Re-enclose is a no-op for atoms/Null, so:
  `comp ⍬ → ⍬`, `comp ⊂ 1 2 3 → ⟨⟨1 2 3⟩⟩` (a rank-0 box), `comp ⊂⊂ 1 2 3` → depth 3.
- rank>0 array → `CollapsedArrayImpl.make(v)` — preserve outer dims, collapse each inner
  element once: `comp 1 2 3 → ⟨1 2 3⟩`, `comp (1 2)(3 4) → ⟨⟨1 2⟩ ⟨3 4⟩⟩`,
  `comp 3 0 ⍴ 3` keeps shape `⟨3 0⟩`.
- non-array (scalar/string/Null) → identity.

First draft got depth wrong (disclosed the box WITHOUT re-enclosing). Fixed by routing the
rank-0 branch through `self.enclose(self.collapse(inner)?)`. Verified every probe below matches
the oracle byte-for-byte.
