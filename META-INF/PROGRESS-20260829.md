## P2 scalar function layer — divergences discovered

| Probe | Oracle | Port | Status |
|-------|--------|------|--------|
| `1 0 1 ⊂ 1 2 3` | `⟨⟨1⟩ ⟨3⟩⟩` | `((1 2 3))` | ❌ partitioned enclose broken |
| `⍕ 2 3⍴⍳6` | `"012\n345\n"` | `"012345"` | ❌ matrix formatting missing |
| `~ 3` | `Error: Operation not supported` | `Error: Invalid argument to logic function` | ⚠️ different error text |
| `typeof "hello"` | `kap:array` | `kap:string` | ⚠️ type mismatch |
| `⊃ 2 3⍴⍳6` | boxed frame | `(0 1 2 3 4 5)` | ⚠️ display divergence |

### Root causes
1. **Partitioned enclose `⊆`/`⊂`**: The partitioned form (dyadic with boolean left) isn't implemented — it just encloses the whole argument
2. **Matrix formatting**: The `⍕` formatter doesn't emit newlines between rows for 2D arrays
3. **~ monadic**: Error message text differs (could align to oracle's "Operation not supported for value")
4. **typeof**: String type detection wrong (Kap treats strings as arrays of chars)
