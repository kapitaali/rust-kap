## [2026-08-25] P6 — native quad constants + `declare(:const)` enforcement + `use()` ns-leak fix

### Context & oracle-first ground truth
P5 closed; per ROADMAP §9 P6 is next. Probed the oracle (fresh kap-jvm-text):
- `⎕A/⎕a/⎕d` are char vectors (26/26/10 long); read-only: `⎕A ← 5` →
  `Error at: 1:1: Assignment to constant variable: kap:⎕A`.
- `declare(:const …)` syntax is **`declare(:const <symbol>)`** (a keyword name +
  symbol, NOT a value — my first guesses `declare(:const foo 5)` errored
  `Unexpected token: ParsedLong`). Marking an existing var const then reassigning →
  `Assignment to constant variable: default:x`.
- `typeof ⎕A` → `kap:array` (oracle) — a character *vector* is type `array`.

### Kotlin ground truth (read, not run)
- `repl/repl-builder.kt:351` `engine.assignConstantVariable(...)` registers `⎕argv`
  (and the quad constants) as read-only globals in the core namespace.
- `parser.kt:1156` `processConst()` marks the *existing* binding's
  `binding.storage.isConst = true`; `processDeclare` (:1172) routes `declare(:const …)`
  to it. The declaration name must be a **keyword** (`:const`), and the argument is a
  symbol, not a value.
- `engine.kt:875` `assignConstantVariable` sets `binding.storage.isConst = true`.
- `use()` (and a `namespace("…")` directive inside an included file) is **scoped** to
  that file — Kotlin restores the caller's namespace on return.

### Changes (committed)
1. **`use()` namespace-leak fix** (`evaluator.rs:eval_string_in_env_tolerant`, ~:477):
   the `namespace()` builtin sets `ns_registry.current` globally and the port never
   restored it after `use()`. The REPL's auto `use("standard-lib.kap")` ends in
   `namespace("man")` (fhelp.kap), leaving the interactive namespace `man` — so
   `x ← 5 ⋄ declare(:const x) ⋄ x ← 6` reported `man:x` instead of oracle `default:x`.
   Now `eval_string_in_env_tolerant` snapshots `current` and restores it after the
   file evaluates (mirrors Kotlin `use()` scoping). Borrow fixed (`borrow().clone()`
   before `replace` — first attempt panicked `RefCell already borrowed`).
2. **Curated rows** (`conformance.rs:649`): added `⎕A/⎕a/⎕d` + `⍴` + `⎕A[0]`/`⎕A[0 1 2]`
   value rows; documented the 3 const-error-text cases (harness can't assert messages).
3. **Lib `#[test]`s** `eval_quad_constants_p6` + `eval_const_enforcement_p6` (lock values
   + const rejection via `Engine::eval_string(...).is_err()`).
