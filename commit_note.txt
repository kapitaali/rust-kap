## Status / what is implemented
- `∇ name { body }` and `∇ (x;y) name (a;b) { body }` traditional functions (component-list grammar
  matching Kotlin parser.kt 694-820).
- `name ⇐ fn-expr` and `name ← fn-expr` both define a first-class function (FnAssign → UserFn).
- Named + anonymous self-recursion via `⍓` (OUTER_CALL_SYMBOL): bound for named ⇐/`∇` AND for bare
  blocks (`{ … } 1`); split clamped to params.len() to avoid panic.
- `≡` (Compare/depth), `⊢` (Identity), `⊣` (Hide), `⍓` added to is_primitive_op.
- Fork `a « b » c` (and 2-train `a « b »` with optional c), trains, derived `f/` `f¨`.
- **Operators**: `∇ (x foo) a { 10 ⍞x a }` (one fn operand) and `∇ (x foo y) a { … }` (two fn
  operands) → stored as `APLValue::UserOp`. Operator calls `+foo 2`, `-foo+ 3` parsed as
  `Instr::OpCall{op, left_fn, right_fn}` and evaluated by `apply_user_op` (function operands
  wrapped and bound to op_left/op_right; body applied to data args).
- **`⍞`** (ApplyToken) → `Instr::DynamicRef{name}` = dynamic function reference (fetch var value
  as function, apply). Faithful to Kotlin `DynamicFunctionDescriptor`.
- Parser tracks `known_ops` (seeded from env.operator_names() each statement) so operators are
  recognized as operators, not stranded values.
